Millcreek, UT | Regulatory Mapping

Alcohol Spacing Regulations

A zoning map and public web app for Millcreek's alcohol establishment spacing requirements — turning a legal distance rule into something planners and business owners can actually check for themselves.

ToolsArcGIS Pro
DeliverablesMap + web app
AudiencePlanners, business owners, public
AccessQR code on map, linked app

Alcohol-establishment spacing rules are the kind of zoning detail that's easy to state in an ordinance and hard to actually check without a map: how close is too close to a school, a church, or another licensed establishment? This project turns Millcreek's spacing requirements into a map first, then a public web application on top of it.

From static rule to interactive tool

The base map shows zoning and spacing requirements for alcohol-serving establishments across the city. Rather than stop there, the same data feeds an online application that lets city planners, prospective business owners, and residents interact with the regulations directly — checking a specific address or area instead of interpreting the ordinance and a static map side by side.

Designed to be found

A QR code on the printed map links straight to the live application, so the two versions — reference map and interactive tool — stay connected instead of living as separate, disconnected resources.
