About

Millcreek's first dedicated GIS hire, in 2019. The role kept absorbing the city's spatial infrastructure — and is now built around enterprise governance as much as cartography.

A GNSS field program, an FAA Part 107 drone program, a citywide stormwater inventory for MS4 compliance, the 2021–2023 migration off ArcMap, and Millcreek's first Esri Enterprise Agreement. Currently pushing further toward data engineering — comparing the ArcGIS API for Python against GeoPandas on real Utah datasets.

  • Enterprise ArcGIS Online — governance, ISO 19115-3 metadata, licensing
  • Python / SQL pipelines — parcel, permitting, regulatory data
  • Experience Builder SDK apps — incl. a Node.js Nearmap integration
  • GNSS/RTK survey · FAA Part 107 · print cartography
