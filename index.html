About

Most of the work is not the map. It is the governance, the data pipelines, and the systems that keep the map correct.

A GNSS field program, an FAA Part 107 drone program, a citywide stormwater inventory for MS4 compliance, the 2023 migration off ArcMap, and Millcreek's first Esri Enterprise Agreement. Now moving further toward data engineering, comparing the ArcGIS API for Python against GeoPandas on real Utah datasets.

  • Enterprise ArcGIS Online: ArcGIS Pro, ISO 19115-3 metadata, Esri licensing
  • Python / SQL pipelines: parcel, permitting, regulatory data
  • Experience Builder SDK apps and custom Node.js widget integrations
  • GNSS/RTK survey · FAA Part 107 · digital and print cartography
