# Brian Busch Portfolio

A dependency-free static GitHub Pages site for cartography, GIS projects, and short notes.

## Edit content

- Homepage: `index.html`
- Projects: `projects/index.html`
- Notes: `notes/index.html`
- About: `about/index.html`
- Styles: `assets/css/site.css`
- Behavior: `assets/js/site.js`

## Publish

This repository is ready for GitHub Pages as plain static HTML. No Jekyll, Ruby, Node, or build step is required.
