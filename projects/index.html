Personal Project | 2026

Western Water Dashboard

Reservoir storage, mountain snow, and drought for eleven western states, in one ArcGIS Maps SDK for JavaScript 5.1 application. It covers more than 400 reservoirs, 639 snow measurement sites, and 75 drainage areas. A Python pipeline rebuilds the data each morning through GitHub Actions. Most of the code was written by artificial intelligence (AI) agents under written rules, with human review on every change.
