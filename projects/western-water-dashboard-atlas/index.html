Western Water Dashboard

System atlas

Three diagrams of the same system. Each one answers a different question. Open a diagram to search it, follow one relationship, or play a short guided view.

Open the dashboard · Read how it was built · Source on GitHub

  • Daily water data path

    Nine official storage providers, one snow service, and the U.S. Drought Monitor reach three Python jobs. The jobs write committed payloads. The payloads are copied into the site and read in the browser.

  • Typed browser runtime

    What a page does after it opens. Loaders check every file before use, pure models do each calculation once, and the address bar carries the view that a reader shares.

  • Morning refresh run

    The 12:00 UTC job. Three subjects refresh independently, a failed subject keeps its last verified file, and three named conditions each open an issue that closes itself.

This is a snapshot. It shows the system at commit 4337697 of 2026-09-10, checked on 2026-09-11. The dashboard keeps changing, so the diagrams get older. The repository holds the current architecture.
