About

Brian Busch, GISP

I'm a GISP-certified Senior GIS Analyst at the City of Millcreek, where the work splits fairly evenly between cartography and the systems and data underneath it. I administer an enterprise ArcGIS Online organization (1,600+ items, 50+ users), write Python pipelines that move parcel and permitting data into production SQL systems, and build custom web apps on the ArcGIS Experience Builder SDK — alongside public-facing maps like Millcreek's Future Land Use Map, a 2025 Esri UC Map Gallery finalist.

I'm actively building toward more data engineering and enterprise data management: recent personal work compares the ArcGIS API for Python against GeoPandas/pandas on real Utah datasets, including a live reservoir drought dashboard built on the ArcGIS Maps SDK for JS. This site collects that range — finished maps, data-pipeline notes, and the design decisions behind both.

What I publish here

  • Cartography and print-map layouts
  • Enterprise GIS administration and data-governance notes
  • Python and SQL data-pipeline and automation writeups
  • Spatial analysis notes and data-method writeups
  • Small cartography notes about labels, palettes, hierarchy, and simplification
